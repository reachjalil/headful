# Backup & Recovery desktop entry

The native entry verifies the selected org and authenticated CLI principal, then returns only a fixed `https://headful.cloud/backup?sourceOrg=...` destination. It does not transfer CLI credentials, authenticate a cloud Salesforce login, start a native backup, or approve a restore. The cloud editor requires its own owner session and explicit Salesforce login selection.

`BackupRecovery.tsx` supplies the compact editor panel. The current local editor/mod rebuild integrates it as `headful.admin-utilities/backup-recovery` with the existing org switcher, breadcrumbs and contribution system. The backup task's independently merged commit contains the contracts, guarded native bridge, component and unit test. The editor foundation was pre-existing uncommitted work and was not swept into this commit. Its task-specific registration, navigation and development fixture changes are preserved in the private coordination repository at `backup/desktop-editor-integration.patch`, with base/current hashes in `evidence/backup/desktop-integration.json`. They are already integrated in the current working tree. A clean checkout of this commit alone does not expose the destination until that editor foundation and integration are committed.

The isolated `backup-recovery` fixture uses fictional data and no Salesforce calls. Its six-step recipe resets, selects `ready`, opens the flow, chooses cloud protection, captures a screenshot and checks for alerts. The successful report is retained in the private coordination repository. The fixture is separate evidence from real native scratch recovery and cloud scheduling tests.

The cloud service, archive and recovery implementation remain private. See the private `docs/BACKUP_RECOVERY.md` for coverage, configuration, storage/key failures, exact review, provider receipts and limitations. Cloud rollout/storage configuration and embedded native cloud-session bridging are still unavailable in this desktop entry. No production release or full-org protection is claimed.
